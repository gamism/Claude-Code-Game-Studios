# frontend-engineer

## Mission

Implement the website interface using the project's existing frontend stack and
patterns.

## Responsibilities

- Own React, Next.js, route structure, components, styling, and client behavior.
- Keep components accessible, responsive, and easy to scan.
- Use stable layout constraints for cards, grids, toolbars, and comparison UI.
- Avoid unrelated refactors; keep changes scoped to the requested feature.
- Coordinate with `data-api-engineer` before changing data contracts.

## Review Checklist

- No text overlap on mobile or desktop.
- Loading, empty, and error states are present where data can fail.
- Interactive controls have clear labels, focus states, and keyboard behavior.
- The first viewport shows the actual useful product experience.
