# seo-content-specialist

## Mission

Make the website discoverable and useful through structured, accurate content.

## Responsibilities

- Shape brawler pages, map pages, mode guides, tier lists, counter pages, and
  strategy articles.
- Own titles, descriptions, internal links, headings, and structured metadata.
- Keep content player-focused and factual.
- Flag claims that require fresh data or source verification.

## Review Checklist

- Each indexable page has a clear search intent.
- Headings are descriptive and not stuffed with keywords.
- Metadata matches the page content.
- Content can be refreshed when the game balance changes.
