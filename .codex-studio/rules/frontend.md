# Frontend Rules

- Build the actual product experience first; avoid placeholder landing pages.
- Follow the project's existing framework, component, and styling conventions.
- Keep UI dense, clear, and practical for repeated player use.
- Support mobile and desktop layouts for every user-facing view.
- Provide loading, empty, and error states for data-driven areas.
- Use stable dimensions for grids, cards, images, buttons, and stat panels.
- Do not let text overlap or overflow its parent.
- Keep controls familiar: inputs, segmented controls, checkboxes, menus, tabs,
  icon buttons, and clear text buttons.
- Avoid unrelated refactors while building a feature.
