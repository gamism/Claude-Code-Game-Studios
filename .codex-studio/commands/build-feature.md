# Command: /build-feature

Use this command only when product scope and planning artifacts are already
approved.

## Required Inputs

- Approved product brief
- Approved UX brief or clear page behavior
- Approved data/API brief if the feature uses data
- Approved SEO/content brief if the feature creates indexable pages

## Routing

Use:

- `workflows/build-feature.md`
- Tier 3 implementation roles

## Rules

- Do not use this command to skip Tier 1 or Tier 2.
- Implementation agents must record changed files.
- Verification still requires Tier 4.
