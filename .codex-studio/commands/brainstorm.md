# Command: /brainstorm

Use this command when the user has no clear product direction yet.

## Goal

Explore project ideas without committing to implementation.

## Process

1. Ask what topic, audience, or problem space the user is interested in.
2. Generate 3 to 5 product directions.
3. For each direction, describe:
   - target user
   - core value
   - first useful version
   - difficulty
   - risks
4. Ask the user to choose one direction or combine parts of several.
5. When one direction is chosen, route to `/start` option 2: vague concept.

## Rules

- Do not create code.
- Do not create a final product brief.
- Do not over-specify features before the user chooses a direction.
