# Workflow: Create Content Page

Use this workflow for brawler pages, map pages, mode guides, counter guides,
build pages, tier lists, or strategy articles.

## Steps

1. `product-lead` identifies the page intent and audience.
2. `seo-content-specialist` drafts the page structure:
   - primary search intent
   - title and description
   - headings
   - internal links
   - refresh cadence
3. `data-api-engineer` identifies dynamic fields and freshness requirements.
4. `ux-designer` reviews scanability, filters, and comparison needs.
5. `frontend-engineer` implements the page or template.
6. `qa-tester` checks links, metadata, content rendering, and responsive layout.

## Completion Criteria

- The page answers one clear player question.
- Dynamic data is labeled or cached honestly.
- Internal links help players continue useful tasks.
- Metadata is specific to the page.
